## Resume fixes (do these this week)

1. **"1000 events/min" undersells the indexer.** That is about 17 events/sec, which reads as small. Report peak throughput, p99 latency, reorg handling, or chains indexed. Drop the number if you can't make it bigger.
2. **Quantify the protocols.** Add TVL, volume, users, or "$X secured" for the Oddz, Novastro vault and Nunchi perps work. Hiring managers look for these numbers first.
3. **Add proof links.** Link an audit report that names your fixes, a verified contract on a block explorer, or a public GitHub repo. Right now the GitHub link is the only evidence.
4. **Add the missing 2026 keywords** (if true): `viem`, `Foundry invariant/fuzz testing`, `Halmos/Certora` (formal verification), `EIP-7702`, `Uniswap v4 hooks`, `ERC-7683 (intents)`, `L2/OP Stack`, `cross-chain messaging (LayerZero/CCIP)`.

## Upskilling: are your skills outdated?

**No.** Perps, vaults, AA, RWA and audit experience are what senior DeFi postings ask for. The highest-paid premiums are **smart contract security, Rust, ZK and MEV** ([crypto.jobs](https://crypto.jobs/most-in-demand-web3-skills-2026)). To stay current:

| Priority | Skill | Why |
|---|---|---|
| 🔴 High | **Security depth:** Foundry invariant testing, Halmos/Certora, audit contests on Code4rena/Cantina/Sherlock | Lifts you from builder to builder-plus-security, which pays the biggest premium. 2–3 contest findings on your resume make a strong signal |
| 🔴 High | **AI-first dev workflow:** Claude Code/Cursor for contracts and tests, AI-assisted audit tools, writing MCP servers for on-chain data | Many companies now ask about this in interviews. You already have RAG and agents, so show it applied to Solidity |
| 🟠 Med | **Agentic payments / agent identity:** ERC-8004, x402, agent wallets (session keys, 7702) | A fast-growing niche where you already have rare hands-on experience (ERC-8004/8183). Market it harder |
| 🟠 Med | **EIP-7702 + intents (ERC-7683)** | The next step after your ERC-4337 work |
| 🟡 Low | **Rust:** keep Anchor current, try a Stylus (Arbitrum) or SVM side project | Rust premium; also opens Solana roles |
| 🟡 Low | **ZK basics** (Noir or SP1) | Highest scarcity premium; a long-horizon bet |
