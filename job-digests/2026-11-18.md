## Today's one improvement: security positioning
Three of today's seven top roles are security roles. Hiring in that area is strong, and your audit-lifecycle experience is rare among builders.
1. **Add a "Security" line to the resume summary.** For example: "Owned external audits with Quantstamp & Zellic end-to-end; adversarial review of liquidation, oracle and settlement paths." Right now this point is buried in bullet 3 of Nunchi.
2. **Write one public security artifact this week.** Either a Foundry invariant test suite for an ERC-4626 vault (inflation/donation attack, rounding direction), or a write-up of a liquidation/oracle edge case you found at Nunchi (sanitized). Link it from the resume and GitHub. Security firms (OpenZeppelin, Hexens, Spearbit) weigh public work heavily.
3. **AI angle:** run an LLM-assisted review pass (Claude Code, alongside Slither/Aderyn) on that same vault, and note what each tool caught and missed. It shows an "AI-first security workflow", which both protocol teams and audit firms are now asking about.
