### Upskill Roadmap — Priority Order

#### Priority 1: Zero-Knowledge Proofs (ZK) — 2-3 month investment
**Why:** ZK is the single highest-paying gap in your profile. zkRollups, zkEVMs (zkSync, Scroll, Polygon CDK) are the backbone of Ethereum scaling in 2026. Engineers who can write circuits + smart contracts command $30k–$80k premium.

**What to learn:**
- Start: [ZK Whiteboard Sessions](https://zkhack.dev/whiteboard/) — free video series
- Tooling: Circom (circuit language) + snarkjs
- Higher-level: Noir (Aztec's ZK language, Rust-like syntax you'll pick up fast)
- Applied: Build one ZK proof for a DeFi use case (e.g., private balance proof, ZK oracle)
- Resource: https://www.rareskills.io/zk-book (free, excellent)

#### Priority 2: AI Agent Infrastructure for Web3 — ongoing (you already have a head start)
**Why:** 60%+ of web3 jobs will require AI skills by 2026. You built ERC-8004 marketplace — most engineers haven't. Extend this advantage.

**What to build/learn:**
- Python basics for LLM integration (LangChain, LangGraph for agent orchestration)
- MCP (Model Context Protocol) — you already use Claude Code; build custom MCP servers for blockchain data
- ElizaOS / GOAT (agent framework for web3) — understand the stack
- On-chain AI agent patterns: proof-of-work verification, agent staking, slashing
- Write a blog post or tweet thread about ERC-8004 — you're one of the few who shipped it in production

#### Priority 3: Intents & Solver Networks — 1 month study
**Why:** UniswapX, ERC-7683, Cowswap — the new DeFi UX layer. Protocols are moving from AMMs to intent-based execution. This pairs with your cross-chain SDK experience.

**What to learn:**
- ERC-7683 (cross-chain intents standard)
- UniswapX architecture and solver economics
- 1inch Fusion+ intent flow
- How to write a solver (TypeScript + Solidity, fits your stack perfectly)

#### Priority 4: Formal Verification — 1-2 months
**Why:** You worked with Quantstamp/Zellic — formal verification is the next step for senior security work. Certora Prover is the industry standard.

**What to learn:**
- Certora Prover + CVL (Certora Verification Language)
- Halmos (Foundry-native symbolic testing — easier entry point)
- Echidna (fuzzing — likely already familiar from Trail of Bits tooling)

#### Priority 5: L2/Rollup Architecture (awareness level)
**Why:** Many protocols deploy on rollups or launch their own app-chains. Good for interviews.

**What to learn:**
- OP Stack (Optimism Superchain) deployment and customization
- Arbitrum Orbit (custom L3 chains)
- EigenLayer AVS design patterns (re-staking, middleware contracts)
- How sequencers, data availability layers (Celestia, EigenDA) work conceptually
