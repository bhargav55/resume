# Web3 Job Hunt System

## Setup

```bash
pip install anthropic
export ANTHROPIC_API_KEY=your_key_here
```

## Run Daily Report

```bash
# Print to terminal
python daily_jobs.py

# Print + save to reports/YYYY-MM-DD.md
python daily_jobs.py --save
```

## What the report gives you

Each morning you get:
- **8-10 specific job openings** matched to your exact profile (CLOB/perps, AI agents, ERC standards)
- **Cold outreach targets** — companies not posting but would hire you
- **One skill to work on today** with a specific resource
- **AI-first signal** — what AI skill is appearing in web3 job posts this week
- **Resume tweak of the day** — surgical improvement to one bullet or section
- **Skill currency check** — which of your skills are hot vs fading
- **5-item action checklist** prioritized by impact

## Reports Archive

Past reports are saved in `reports/YYYY-MM-DD.md`.
