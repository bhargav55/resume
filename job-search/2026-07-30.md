# Daily improvement recommendations

## Sharpen core EVM/Solidity (your primary lane)
- **Foundry fluency**: if you're not already fuzz-testing and invariant-testing every contract with `forge fuzz`/`forge invariant`, add it this week — it's now table stakes in interviews.
- **Security depth**: run your own or past contracts through Slither + Echidna, then try one Code4rena or Sherlock/Cantina contest per month. Contest leaderboards double as a public track record recruiters check.
- **Formal verification exposure**: skim Certora or Halmos basics — senior/lead EVM roles increasingly list this as a plus.
- **Account abstraction (ERC-4337) and L2 rollup internals** (OP Stack, Arbitrum Orbit, restaking via EigenLayer): these are the hottest sub-specialties right now (see LayerZero, Sei, Hastra postings above) — pick one and go deep enough to talk fluently about tradeoffs in interviews.

## TypeScript backend (your other primary lane)
- Stay current on `viem` (displacing ethers.js in a lot of new stacks) and indexing frameworks — Ponder, The Graph, Subsquid. Backend job posts increasingly want "index chain data into Postgres, serve via TS API" experience, not just contract-writing.
- Practice building one small end-to-end piece: a contract + an indexer + a TS API + a minimal frontend hook. That full-stack narrative is exactly what "Web3 Fullstack Engineer" postings (like Xsolla above) are screening for.

## Rust/SVM — keep warm, don't over-invest
Given EVM is your primary target, spend maybe 1 session/week keeping Anchor/Rust sharp rather than deep-diving — enough to credibly claim it as a secondary skill in interviews, not enough to dilute EVM depth.

## AI-first hiring — this is now a real screening filter
Search data from this week: **43% of candidates say they avoid companies with no clear AI/automation focus, and 61% report being asked directly about their AI workflow in interviews.** Concretely, this week:
1. **Use an AI coding agent daily in your actual workflow** (Claude Code / Cursor) for scaffolding contracts, writing tests, and drafting NatSpec docs — then be ready to talk in interviews about where you trust it and where you don't (this is the actual question being asked, not "do you use AI").
2. **Learn AI-assisted auditing tooling**: CertiK's AI auditor and Sherlock's AI-triage layer are now part of real audit pipelines (see CertiK postings above) — understanding how AI scanners complement Slither/Echidna is a differentiator, especially since CertiK itself is hiring for exactly this overlap.
3. **Watch the "AI agents on-chain" space** — agent wallets, x402-style agent payments, autonomous on-chain agents. This is where EVM + AI is converging fastest and where new roles are likely to appear over the next few months. Even a small side project (an agent that can read a contract's state and execute a transaction) is a strong portfolio signal right now.
