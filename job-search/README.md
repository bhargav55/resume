# Daily Job Search Log

This folder is refreshed daily (as a scheduled routine) with curated Web3 /
Solidity / EVM / TypeScript job leads matching Bhargav's profile: ~10 yrs
engineering, senior blockchain (EVM smart contracts, DeFi/perps, account
abstraction, RWA, security audits), TypeScript/Node backend, secondary
Rust/Anchor (Solana), plus hands-on AI/LLM agent-building experience.

- `YYYY-MM-DD.md` — that day's curated opportunities + notes.
- `../UPSKILL_PLAN.md` — standing skill-development plan, updated when it
  meaningfully changes rather than every day.

## Job boards to check yourself every day (bot-protection blocks automated fetches)

Automated fetching of these boards returns HTTP 403 (Cloudflare/bot
protection), so exact "posted X hours ago" listings can't be scraped
directly each run. Bookmark these and skim them daily — 2-3 minutes each:

- https://web3.career/remote+solidity-jobs
- https://web3.career/smart-contract-jobs
- https://web3.career/remote+typescript-jobs
- https://cryptojobslist.com/solidity
- https://cryptojobslist.com/remote
- https://cryptocurrencyjobs.co/
- https://sailonchain.com/jobs/skill/solidity
- https://wellfound.com/role/r/smart-contract
- https://remotive.com/remote/jobs/software-development (filter "web3"/"blockchain")

Consider setting up email/RSS alerts on web3.career and cryptojobslist.com
for "solidity", "smart contract", "account abstraction" — that gets you
same-day notifications without relying on scraping.
