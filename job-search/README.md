# Job Search Tracker — Bhargav Kacharla

Automated daily job-search digest for web3 roles (Solidity/EVM smart contracts,
TypeScript backend, Rust/SVM secondary). Generated on a recurring schedule.

- `daily/YYYY-MM-DD.md` — each day's fresh job leads, sourced from web3.career,
  CryptoJobsList, Cryptocurrency Jobs, Wellfound, and direct company boards.
- `upskilling.md` — living list of skill-gap recommendations and AI-in-workflow
  suggestions, revisited/updated as the market shifts.

## Target profile
- Primary: Solidity smart contract engineering, EVM internals, DeFi/perpetuals,
  account abstraction (ERC-4337), RWA/compliance (ERC-3643), protocol security.
- Secondary: TypeScript/Node.js backend, on-chain indexers, WebSocket services.
- Tertiary: Rust/Anchor on Solana (SVM).
- Emerging edge: AI agents for on-chain execution (ERC-8004/8183), AI-assisted
  smart contract auditing — increasingly a differentiator as web3 firms go AI-first.
