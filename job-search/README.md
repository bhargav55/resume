# Job Search Tracker

Automated daily tracker for Bhargav Kacharla's Web3 job search (Solidity/EVM smart contracts,
TypeScript backend, Rust/Anchor on SVM as a secondary skill).

- `LEADS.md` — running log of open roles found each day, newest entry on top. Each entry
  lists company, role, comp (if public), remote status, a link, and why it fits the profile.
  Postings are surfaced from public job boards via web search; **always verify the listing is
  still open before applying**, since aggregator pages can lag the source by a few days.
- `RECOMMENDATIONS.md` — standing advice on daily habits, AI-workflow upskilling, and
  where the current skill set may be under- or over-indexed for where the market is heading.
  Updated only when the advice actually changes, not every day.

This directory is maintained by a scheduled Claude Code routine and is meant to be skimmed
each morning before applying.
