# Job Search Tracker

Automated daily job-search runs for Bhargav Kacharla — Solidity/EVM smart
contract engineer, TypeScript backend, some Rust/SVM experience.

## Structure

- `leads/YYYY-MM-DD.md` — job leads pulled that day, with links, comp, and a
  short note on fit against the resume.
- `recommendations.md` — running log of upskilling advice (AI-in-workflow,
  skill gaps, market trend notes), updated as the market shifts.

## How to use this

1. Open today's file under `leads/`.
2. Click through, verify the posting is still open, and apply directly on
   the company/board site (this tracker only surfaces leads, it doesn't
   auto-apply).
3. Check `recommendations.md` periodically for skill-building suggestions.

## Primary sources checked each run

- [web3.career](https://web3.career/) — filtered by `solidity`, `evm`, `smart contract`, `backend`
- [cryptojobslist.com](https://cryptojobslist.com/remote)
- [remote3.co](https://www.remote3.co/)
- [cryptocurrencyjobs.co](https://cryptocurrencyjobs.co/remote/engineering/)
- Wellfound / Arc.dev remote Solidity boards

Postings on these boards churn fast and get refilled/removed within days —
always verify a listing is still live before spending time tailoring an
application to it.
