# Job Search Tracker — Bhargav Kacharla

Automated daily job-hunting assistant for Web3 / Solidity / EVM roles (primary),
TypeScript backend roles (primary), and Rust/Solana roles (secondary).

## Structure

- `digests/YYYY-MM-DD.md` — daily list of open roles worth applying to, gathered
  from web3.career, cryptojobslist.com, cryptocurrencyjobs.co, Wellfound, Arc.dev,
  and company career pages.
- `UPSKILL.md` — living document of skill-gap analysis and upskilling
  recommendations (AI tooling, emerging Web3 primitives), updated as the market shifts.
- `APPLIED.md` — running log of roles applied to, so digests don't repeat them.
