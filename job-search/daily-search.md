# Daily Job Search System

## How to Use This System

Each day, a new log file is created in `daily-logs/YYYY-MM-DD.md` with:
- Fresh job opportunities (Tier 1 = apply today, Tier 2 = apply this week)
- One focused upskilling recommendation
- One outreach action

## Target Salary Range (Use as Anchor)

- **Minimum**: $150,000 (remote, strong protocol)
- **Target**: $180,000–$220,000 base
- **Stretch**: $250,000+ (Uniswap-tier, with token grants)
- **India-remote for US company**: $80,000–$130,000 USD (still strong)

---

## Red Flags to Avoid

- Roles requiring relocation to non-remote cities without strong token comp
- Companies that haven't shipped mainnet contracts
- "Smart contract" roles that are actually just frontend + ethers.js
- Vague equity with no vesting schedule
- Anonymous teams with no audit history
