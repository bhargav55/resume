## Daily improvement plan (rotate one per day)
1. Audit practice: one Code4rena/Sherlock/Cantina contest finding or a past-report read (30-60 min). Also useful: Echidna/Medusa fuzzing and Halmos/Certora formal verification, since invariant testing is now expected in senior roles.
2. EVM currency: Solidity 0.8.2x, transient storage (EIP-1153), EIP-7702 (account abstraction beyond 4337), Uniswap v4 hooks, intent-based systems (CoW, UniswapX), L2 and rollup specifics.
3. AI in workflow: use Claude Code or similar for test generation, invariant suggestions and first-pass audit review. Build a small LLM-assisted Slither triage or fuzz-harness generator and publish it. Namefi and CertiK-style roles ask for exactly this.
4. Gaps to close: Rust/Anchor depth if you want SVM roles, and Move or Cairo only if targeting those ecosystems (low priority).
5. Interviews: one system-design prompt per day (perps liquidation engine, oracle design, indexer reorg handling) and one Solidity gotcha question.
6. Visibility: publish writeups on the perps and 4626 work on GitHub or X. Referrals convert far better than cold applies.
