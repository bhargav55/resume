this (RAG pipeline, agentic smart-contract auditor using MCP + Slither). **Web3 is visibly going
AI-first** — tao.bot and similar "AI-native blockchain" roles are appearing, and even traditional

agent marketplace work at Nunchi is squarely in this niche). Lead with this combination in your
resume summary and LinkedIn headline instead of burying it under "AI Engineer Projects."

   Nethermind, Zellic) given your existing audit-lifecycle experience.
3. **AI tools in your daily dev workflow** — if not already: Cursor/Claude Code for contract
   scaffolding + test generation, an LLM-based Slither-finding triager (you've basically built one —
   consider open-sourcing a stripped version as a portfolio piece).
4. **Deepen Rust/Solana** — it's currently secondary for you but Solana hiring is strong right now;
   even a couple of Anchor-based side projects would let you credibly bid on dual-chain roles.
5. **ZK fundamentals** — a common gap for Solidity-first engineers. Even conceptual fluency
   (Groth16/PLONK basics, common ZK-rollup patterns) is increasingly expected at L2/rollup shops.
6. **Ship the AI-auditor project publicly** — a short write-up or demo video of the agentic
   smart-contract auditor (MCP + Slither + exploit KB) would make a strong portfolio piece for
