# Daily Job Search System

## Every Morning (15 min)

1. Open these 6 tabs in your browser:
   - https://web3.career/defi+solidity-jobs
   - https://cryptojobslist.com/solidity
   - https://cryptojobslist.com/evm
   - https://web3.career/ai-jobs
   - https://cryptocurrencyjobs.co/solidity/
   - https://remoteok.com/remote-ethereum-jobs

2. Sort by "newest" and look for postings from the last 24–48 hours.

3. Apply immediately to anything ≥ 80% match. Do not delay — fresh postings have 10x lower competition.

## Set Up Email Alerts (One-time, 5 min)

- **web3.career**: Create account → set alert for "Solidity" + "DeFi" + remote
- **cryptojobslist.com**: Set email alert for "Solidity", "EVM"
- **LinkedIn**: Search "Solidity Engineer" → turn on job alerts (daily digest)
- **Telegram**: Join @web3jobsbot for live postings

## Weekly (1 hour)

- Check careers pages of your target companies directly (see list in daily jobs file)
- DM or connect on LinkedIn/Twitter with engineers at target companies before applying
- Post one technical update on Twitter/X or Farcaster — recruiters cold-DM active builders

## Tracking

Create a new file in `jobs/` each day: `jobs/YYYY-MM-DD.md`
Copy the template from `jobs/2026-05-28.md` and update with new findings.

## Cover Letter / DM Template

> Hey [name], I've been building [X] at [Y protocol] for [Z years].
> Most recently I shipped a CLOB matching engine for a perpetuals DEX and an on-chain AI agent marketplace.
> I see you're hiring for [role] — would love to chat. Here's my GitHub: [link]

Keep it to 3 sentences max. Builders respond to builders.
