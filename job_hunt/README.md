# Daily Job Hunt System

Each day's report is saved as `job_hunt/YYYY-MM-DD.md`.

To get today's opportunities + skill recommendations, open Claude Code and say:
> "Search for new web3 solidity job opportunities today and update my job hunt report"

## Quick Daily Checklist
- [ ] Check cryptojobslist.com/solidity (filter: new this week)
- [ ] Check web3.career/solidity-jobs
- [ ] Check crypto.jobs
- [ ] Review today's report in job_hunt/YYYY-MM-DD.md
- [ ] Apply to 1-2 Tier 1/2 roles
- [ ] 30 min upskill (ZK → Formal Verification → EigenLayer → MEV priority order)
